# Spider 2.0: Evaluating Text-to-SQL in Realistic Enterprise Settings

## 摘要

Spider 1.0 的后继基准，632 个来自真实企业级数据库使用场景的 text-to-SQL 工作流问题：数据库常含 1000+ 列，分布在 BigQuery、Snowflake 及本地引擎，标准答案经常是数十行、含 CTE 与窗口函数的多步 SQL。结论是企业级场景与学术基准"不同种而非不同度"：最强模型在此基准上的表现断崖式下跌。

## 要点

- **o1-preview 的 code agent 框架只解决 21.3% 的任务**，对比其在 Spider 1.0 上的 91.2%、BIRD 上的 73.0%。
- Spider 2.0-lite 设置下，最强 parser 只答对 **5.7%**。
- 任务常要求理解并检索数据库元数据、方言文档甚至项目级代码库，输出经常超过 100 行 SQL。
- 这是"裸 schema 上 LLM 写 SQL 准确率极低"这一业界共识最硬的学术出处。
