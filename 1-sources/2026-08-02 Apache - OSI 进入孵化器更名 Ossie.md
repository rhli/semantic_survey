# Apache: OSI 进入 Apache 孵化器，更名 Apache Ossie (incubating)

## 摘要

Open Semantic Interchange（OSI）已被 Apache 孵化器接收，更名 **Apache Ossie (incubating)**。规范、社区、使命不变，治理归属与长期轨迹改变。成员名单扩至 50+ 组织。转换器采用 hub-and-spoke 架构：Ossie 核心规范为枢纽，各厂商格式（Snowflake、dbt、Salesforce、Databricks）为辐条，避免两两互转。

## 要点

- 成员名单（官方）：Alation、Anomalo、Atlan、AtScale、Bigeye、BlackRock、Blue Yonder、Carto、Cloudera、Coalesce、Collate、Collibra、Cogniti、Count、Credible、Cube、Databricks、DataHub、Denodo、dbt Labs、Dremio、Domo、Elementum AI、Firebolt、GoodData、Hex、Honeydew、Informatica、Instacart、JetBrains、Lightdash、Mistral AI、Omni、Oracle、Preset、Qlik、RelationalAI、Salesforce、Select Star、Sigma、Snowflake、Solid、Starburst、Strategy、Sundial、ThoughtSpot 等 50+。
- 创始方：Snowflake、Salesforce、dbt Labs（2025-09），Google 早期参与；Databricks、AtScale 等后续加入。
- Salesforce 的表述值得注意："bring your own semantic layer"——用客户在 dbt/Snowflake 的既有投资驱动下游体验，**无论谁在问，答案一致**。
- 进入 Apache 孵化器意味着治理从 Snowflake 主导的工作组转为 Apache 流程——对"这是 Snowflake 的产品吗"的质疑是实质性回应。
