# SQLGlot、OpenLineage、DataHub/OpenMetadata、Kuzu（building blocks 合并笔记）

## 摘要

为 "codegraph for data" 扫描的四类开源构件，合并记一条：SQLGlot（SQL 解析与列级血缘）、OpenLineage/Marquez（血缘事件标准与参考实现）、DataHub/OpenMetadata（带 MCP 的元数据图谱）、Kuzu（嵌入式图引擎，已被 Apple 收购、原仓库归档，社区分叉延续）。

## 要点

- **SQLGlot**：零依赖 Python SQL 解析器/transpiler/优化器，30+ 方言；`lineage` 模块做列级血缘（DAG 上自顶向下追踪列来源）；SQLMesh、Superset、Dagster、dlt 等都在用。它是"理解 SQL 文本"的事实标准构件。
- **OpenLineage**：血缘元数据的开放标准与 API；Marquez 是参考实现（LF AI & Data 孵化）。生产侧集成 Airflow/Spark/Flink/dbt/Dagster，消费侧 DataHub/OpenMetadata/Atlan。
- **DataHub / OpenMetadata**：开源元数据图谱双雄。DataHub 有 OpenLineage REST 端点、Ask DataHub 对话 agent、托管 MCP server；OpenMetadata 在 `/mcp` 暴露 MCP server（JSON-RPC 2.0）。两者都原生支持列级血缘。
- **Kuzu**："图界的 DuckDB"，嵌入式、进程内、亚毫秒、Cypher + 向量 + 全文检索，路径查询比 Neo4j 快 374 倍（厂商口径）。**2025-10 被 Apple 收购后原仓库归档、停止开发**；Vela Partners 分叉（加多 writer 并发）与 LadybugDB 延续。官方 MCP server 存在（getSchema/query/generateKuzuCypher，只读模式）。
