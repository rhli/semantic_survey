# AtScale: Why Open Semantics Matter for Enterprise AI + MCP 页面

## 摘要

AtScale 的开放语义叙事：SML（Semantic Modeling Language）开源为"业界第一个开放的、实现中立的建模标准"，MCP server 把治理语义直接喂给 agent。定位关键词三个：Universal（定义与工具/平台/基础设施解耦）、Open（SQL/MDX/DAX/Python/REST/MCP）、Composable（SML 模块化复用）。

## 要点

- **SML 已开源**（GitHub 有公开仓库）：YAML 对象集合（dataset、dimension、metric 等），存 Git 仓库，程序化建模。容器化版本迁移强制走 SML。
- **MCP server**：agent 可发现模型、理解维度与指标、执行治理查询、用一致业务逻辑综合洞察；兼容 2026-07-28 的 stateless MCP 规范。
- One-Click Modeling：自动生成语义模型的入口（AI 辅助建模）。
- 客户基础：Fortune 1000 级别，"十多年基础设施优先的建设"。
- 官方主张语义层是 "semantic-first AI architecture" 的前提：可信指标定义、实体关系、治理规则、开放标准（SML）、MCP 接入。
- 发布《2026 State of the Semantic Layer》年度报告（营销资产，可作行业叙事风向）。

## 关联

- 支撑 [[AtScale]] 公司页深填。
- SML 开源 + OSI 成员身份，使 AtScale 在"开放"叙事上比实际产品开放性看起来更激进——SML 开源的是**语言**，引擎仍闭源，与 MetricFlow（引擎开源）是两种不同的开放。
